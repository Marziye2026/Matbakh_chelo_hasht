# سامانه سفارش غذای سازمانی — مطبخ چلو هشت

نسخه MVP واقعی و قابل توسعه برای مدیریت چندشرکتی سفارش غذا.

## امکانات
- پنل صاحب رستوران
- پنل مدیر شرکت
- پنل پرسنل
- تفکیک کامل داده‌های شرکت‌ها
- تقویم و تاریخ شمسی در رابط کاربری
- منوی روزانه ۴ غذا
- هر پرسنل فقط یک سفارش برای هر روز
- قفل سفارش بعد از ثبت نهایی
- عدم ارسال قیمت غذا در API پرسنل
- گزارش سفارش‌ها
- خروجی CSV قابل باز شدن در Excel
- SQLite برای شروع سریع؛ قابل مهاجرت به PostgreSQL

## اجرا
Node.js نسخه 20 یا بالاتر نصب باشد.

```bash
npm install
npm start
```

سپس:
http://localhost:3000

## ورود آزمایشی
صاحب رستوران:
- نقش: صاحب رستوران
- نام کاربری: admin
- رمز: 123456

مدیر شرکت نمونه:
- نقش: مدیر شرکت
- کد شرکت: C100
- کد مدیر: M100
- رمز: 123456

پرسنل نمونه:
- نقش: پرسنل
- کد شرکت: C100
- کد پرسنل: E1001
- رمز: 123456

> این حساب‌ها برای راه‌اندازی اولیه هستند و قبل از استفاده واقعی باید تغییر داده شوند.

## ساختار
- `server.js` بک‌اند و API
- `db.js` دیتابیس و seed
- `public/` رابط کاربری
- `schema.sql` ساختار دیتابیس

برای استقرار نهایی پیشنهاد می‌شود SQLite به PostgreSQL منتقل شود و HTTPS، مدیریت نشست/توکن، بکاپ و مدیریت کاربران سازمانی روی سرور فعال شود.
